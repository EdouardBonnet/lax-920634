# Explicit subcubic expanders and linear treewidth

A Lax submission (`lax-920634`) with complete Lean proofs of a deterministic
linear-time word-RAM construction of arbitrarily large finite simple subcubic
expanders, and a linear treewidth lower bound for the same graphs.

Put `K = 5760000`, `D = 120^K`, and `d = D^2`. The graph at level `k` has
`N_k = d (D^4)^(k+1)` vertices. For every vertex set `S` containing at most
half the vertices, its edge boundary satisfies

    |∂S| ≥ |S| / (8d).

Every vertex has at most three distinct neighbors, and

    N_k ≤ (24d + 1) (tw(H_k) + 1).

For every threshold there is a member above that threshold satisfying
`N_k ≤ (48d + 2) tw(H_k)`. All constants are independent of `k`.

## Construction

1. Enumerate tables of thirty maps on the **fixed** set of `D^4` vertices.
   Choose the first table whose rows are permutations and for which every
   set of at most half the vertices has at least a tenth of its vertices
   moved outside by some row. The existence proof is a finite counting
   argument; the constructor itself is a deterministic list scan.
2. Include forward and inverse permutation darts and sixty stationary darts.
   The resulting degree-120 lazy graph has spectral bound
   `1 - 1/1440000`. Raise it to the fixed power `K`. This produces a
   degree-`D` seed on `D^4` vertices with spectral bound at most `1/5`.
3. Square the seed. At each subsequent level, square the preceding graph
   and take its zig-zag product with the same seed. The numbered rotation
   map is specified directly by recursive integer formulas. The regular
   tower has degree `d` and spectral bound at most `2/5`.
4. Replace every regular vertex by a path of its `d` ports. Pair ports
   using the regular rotation involution. Remove loops and merge coincident
   edges by taking the simple undirected graph generated by these edges.

## Linear-time RAM construction

The fixed program in [RamProgram.lean](proofs/Lax920634Proofs/RamProgram.lean)
uses the registered [Lax word RAM](https://laxarchive.org/lax-808846/).
It receives `[n]`, a one-word order request, and uses the same size selector
as the original construction. Its graph order `N` lies between `n` and
`2dD^4(n+1)`.

The output is **exactly `N+1` words**: the order header followed by the
matching endpoint of each vertex in numerical order. Path edges follow from
the row numbers. [WordEncoding.lean](proofs/Lax920634Proofs/WordEncoding.lean)
proves the header, length, endpoint bounds, and equality of the decoded graph
with the original `H_k`.

The complete checked instruction bound is

    time ≤ 25381 (N + 1), whenever 128 (N + 1) ≤ 2^w.

Thus `O(log(N+1))`-bit words suffice. One fixed program works for every
request and every sufficiently large word width. It uses `O(N)` words of
storage. The theorem counts actual RAM instructions through the registered
verified compiler; it includes table initialization, level selection, every
intermediate table, and the entire output pass.

The program materializes successive rotation tables from the bottom up.
Every new row evaluates a fixed expression of seed and preceding-table
lookups. All old tables occupy consecutive disjoint blocks. Their orders
grow by the fixed factor `D^4`, so their total size is at most twice the final
order. The amortized proof charges each growth stage against the increase in
table size.

The deterministic fixed seed and the level-zero table are embedded as program
literals. Their initialization is charged. Their values are specified by the
finite seed scan, and the program definition is executable; no data depending
on the request or word width are embedded. The enormous fixed seed and
program make this a theoretical construction.

The separate `GraphEncoding.construct` interface retains its fully proved
polynomial-time Turing-machine bound. It accepts a unary size request through
the length of a binary word and outputs a bracket-encoded table with unary
coordinates. The RAM interface uses word-sized vertex labels.

## Proofs and dependencies

The concepts and their annotated proofs cover seed-search correctness,
path replacement, subcubicity, uniform expansion, expansion-to-treewidth,
the two existence statements, the size bound, word-encoding correctness,
linear-time RAM computation, and polynomial-time Turing-machine computation.
There are no `sorry`, admitted proof obligations, or extra axioms in the
proof package. Concept axioms are Lax's statement declarations; each is
discharged by an annotated proof.

The pinned registered dependency `Lax323828Proofs` supplies the full finite
counting, spectral, zig-zag, numbered-tower, and machine-simulation proofs.
`Lax228581` supplies the registered treewidth definition. `Lax808846` and its
proof package supply the RAM semantics, structured language, compiler, and
checked simulation. Reusing their
checked proofs avoids leaving a spectral theorem or complexity claim as an
assumption. The local treewidth argument proves finite tree Helly and the
bramble-to-bag implication, then counts boundaries of components after vertex
deletion. It does not assume a treewidth–bramble duality theorem.

See [the concept package](concepts/Lax920634.lean),
[the proof package](proofs/Lax920634Proofs.lean), and
[the annotated conclusions](proofs/Lax920634Proofs/Results.lean).
The linear-time conclusion is in
[RamLinear.lean](proofs/Lax920634Proofs/RamLinear.lean). The Turing-machine
conclusion is in [Algorithm.lean](proofs/Lax920634Proofs/Algorithm.lean).

## Build and preview

From this directory, run:

```sh
lax build --replay
lax serve --port 8123
```

The local preview is at <http://localhost:8123/>. Proof replay checks the
compiled declarations with Lean's kernel. Run `lax submit` to publish a
replaceable draft in the archive.
